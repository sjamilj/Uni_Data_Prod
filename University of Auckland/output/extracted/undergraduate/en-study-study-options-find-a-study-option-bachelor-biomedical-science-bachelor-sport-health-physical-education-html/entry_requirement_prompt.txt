## `degreeName`

`degreeName` = the **final award** of this course, taken from `Bachelor of Biomedical Science/Bachelor of Sport, Health and Physical Education Conjoint BBiomedSc/BSportHPE` (e.g. `MSc`, `MA`, `MBA`, `MEng`, `MDes`, `BSc`, `BA`, `PhD`).

- It is the award of this course, **not** the entry qualification.
- If `Bachelor of Biomedical Science/Bachelor of Sport, Health and Physical Education Conjoint BBiomedSc/BSportHPE` states a code (e.g. `Master of Design MDes` → `MDes`), use that code.
- If no award is stated → `""`.

## Course level → Bangladesh academic section

The Bangladesh page is JSON with `studyLevels[]`. Use **only** the object whose `studyLevel` matches `undergraduate`:

| `undergraduate` | `studyLevel` value |
|---|---|
| `foundation` | `Foundation` or `Foundation year` |
| `undergraduate` | `Undergraduate` |
| `postgraduate` | `Postgraduate` |

**Critical:** Read requirements from `programs[].requirements[]` in the matching `studyLevel` only. Ignore all other levels.

If the matching level lists several programs (e.g. `Graduate Diploma (Level 7)`, `PG Diploma (Level 8)`, `Masters (Level 9)`), use the program that matches the course award:
- Master's award (MSc, MA, MBA, MEng, MDes, MRes, …) → the **Masters** program
- PGDip / PG Diploma → the **PG Diploma** program
- Graduate Diploma → the **Graduate Diploma** program

For `undergraduate`: do **not** include Bachelor/Master qualifications (those belong to postgraduate).
For `foundation`: do **not** include Undergraduate or Postgraduate levels.
For `postgraduate`: do **not** include Foundation or Undergraduate levels.

## `requirements` array — pick only the matching entry degree

Each item: `{ "degree": "", "grade": "" }`.

Only emit a requirement when **both** a qualification and a grade/score appear in the selected program. Never invent empty placeholders for unused degree types.

Allowed `degree` values (only when stated in the selected program): `HSC`, `A Level`, `Diploma`, `BA`, `BSc`, `BBA`, `BEng`, `BCom`, `MA`, `MSc`, `MBA`, `PhD`.

### Keep only the entry degree that matches `degreeName`

The source may list several entry degrees with the same grade (e.g. BA, BSc, BCom, BEng). Output **only the one** that matches the course award:

| `degreeName` | Keep this entry degree |
|---|---|
| MSc | BSc |
| MA | BA |
| MBA | BBA (if not listed → BSc) |
| MEng | BEng |
| MCom | BCom |
| Any other Master's (e.g. MDes, MRes) | BSc (generic "Bachelor degree") |
| PGDip / PG Diploma | BSc (generic "Bachelor degree") |
| PhD | MSc |
| Bachelor's (BSc, BA, BEng, BCom, …) | HSC |
| Foundation | HSC |

Rules:
- Drop every other degree, even when the source lists it with the same grade.
- If the matching degree is **not** in the selected program, fall back to the generic `BSc` only if the table says so; otherwise return `[]`. Never substitute an unrelated degree.
- Output one object per matching degree (normally exactly one).

Map source labels to allowed values when needed:
- `HSC (Alim)` / `Completion of HSC (Alim)` → `HSC`
- `Bachelor Degree` / `4-year Bachelor degree` → `BSc`
- `Master's Degree` / `2 year Master's degree` → `MSc`

Python also adds a UK-derived `HSC` equivalence row from Stage 1 UCAS / A-Level course-page text when present. Do **not** invent UCAS→GPA conversions in the LLM output.

Typical for undergraduate Bangladesh sections: `HSC`, `A Level`, `Diploma` only.
Typical for postgraduate Bangladesh sections: `BA`, `BSc`, `BCom`, `BEng` (or `BSc`, `MSc`), then filtered by the table above.

### `grade`

Single field: `GPA 3.00`, `CGPA 3.5`, `AAB`, `2:1`, `60%`, `More than 60-65% and above`, etc. **Copy verbatim** from the source. Skip qualifications that have no grade.

GPA conversion happens **only** when the source gives a bare percentage and states a GPA scale:
- 4.0 scale: `60%→GPA 3.00`, `50%→GPA 2.50`, `70%→GPA 3.50` (80→4.00, 75→3.75, 65→3.25, 55→2.75, 45→2.25, 40→2.00)
- Bangladesh HSC/SSC 5.0 scale when stated: `50%→GPA 3.00`, `60%→GPA 3.50`
- If the source says `CGPA 2.5/4.0`, `CGPA 3.5`, or a range / "more than …" wording, copy unchanged. Never convert ranges.
- Never convert NZ-style `GPA 5.0` / `GPE 5.0` values; copy verbatim.
